# Changelog

## 0.5.1 — 2026-10-20

- Distribute only the reusable Skill: move bundled production inputs outside the repository and replace character examples with neutral field structure.
- Retain complete timeline/schema/provider coverage through procedural, non-narrative test fixtures; no production code loads a test fixture.
- Build each production from the user's own story or plan, require an explicit story runtime, and default to a unique external project directory.
- Reject production writes inside Skill copies, extend private-output ignore rules, and audit both tracked content and installation ZIP inputs with a release allowlist.
- Keep managed-install backups and legacy upgrades using opaque tree fingerprints; preserve earlier releases unchanged.

## 0.5.0 — 2026-10-20

- Add sampled optical flow, camera-compensated residuals, region motion, repeated-content and flash/cut triage; uncertain footage requires human review.
- Add schema v2 director packets, action beats, Character Bible costume/expression/state data, Scene Bible and explicit continuity change tracking. Read v1 and offer non-destructive migration.
- Route configured provider/model combinations by verified controls, purpose affinity, preferences or reviewed cost. Record the selected parameters and reason.
- Add a private loopback workbench, exact-hash review records, project/task/cost status, bounded single-shot regeneration, and local re-editing without generation calls.
- Preserve raw and lip-synced assets, support licensed dynamic source imports, sound fades and timed/overlapping music cues with dialogue ducking.
- Add verified managed-install upgrades with a restorable backup, central versioning and separate release acceptance levels.
- Preserve the original 53 offline tests and v0.1.0 release history. No paid provider or complete-film acceptance is claimed by this release.

## 0.1.0 — 2026-10-20
